# Support

## Where to ask

| Channel | Use for |
|---|---|
| [API Documentation](https://open.wanlianyida.com/docs) | API reference, integration guides |
| Repository **Issues** | Bugs and feature requests in a specific repository |
| Repository **Discussions** | Questions, usage experience, best practices |
| [contact@wlyd.com](mailto:contact@wlyd.com) | Technical support & business cooperation |
| [Developer Community](https://open.wanlianyida.com/community) | Community content |

## Picking the right repository

- Protocol/spec questions → [wop-specs](https://github.com/wop-platform/wop-specs)
- SDK usage in a specific language → the matching `wop-<lang>-sdk` repository
  (see the organization profile for the list)

## Security issues

Do not post security vulnerabilities publicly — see [SECURITY.md](SECURITY.md).
