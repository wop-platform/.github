# .github

Default community health files and organization metadata for the [wop-platform](https://github.com/wop-platform) GitHub organization.

Files placed here (e.g. `CONTRIBUTING.md`, `SECURITY.md`, issue/PR templates) automatically apply to **all repositories** in the organization that don't define their own.
