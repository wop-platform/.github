## 🙋‍♀️ About Us

WOP Platform (Wanlian Yida Open Platform) is a one-stop industrial service platform provided by Wanlian Yida for developers and enterprises. Wanlian Yida is an industrial internet company building a new industrial internet ecosystem and a trusted data space across industries. We are committed to:

- 🚀 **Simplified Integration**: Provide easy-to-use APIs and SDKs to make integration effortless
- 🔒 **Security & Reliability**: Enterprise-grade security to safeguard every data interaction
- 🌐 **Multi-scenario Support**: Cover commodity trading, logistics & warehousing, digital finance, digital technology, AI, industry insights, business services and more across all industries
- 📱 **Cross-platform Compatibility**: Support multiple programming languages and development frameworks

## 🚀 Quick Start

1. **Create an account** — Sign up on the [WOP Platform](https://open.wanlianyida.com) and create your application
2. **Pick an SDK** — Choose the official SDK for your language (see the table below)
3. **Start building** — Follow the [API Documentation](https://open.wanlianyida.com/docs) to make your first call

## 📜 Specifications

All public protocol specifications, the unified SDK specification, and cross-language golden test vectors live in [wop-specs](https://github.com/wop-platform/wop-specs):

- [Crypto Strategy Spec](https://github.com/wop-platform/wop-specs/blob/main/crypto/crypto-strategy-spec.md) — `securityReq` algorithm suites, wire encoding contracts, protocol invariants
- [SDK Unified Spec](https://github.com/wop-platform/wop-specs/blob/main/sdk/wop-sdk-spec.md) — the ratified spec behind all official SDKs
- [Golden Test Vectors](https://github.com/wop-platform/wop-specs/blob/main/crypto/crypto-vectors.json) — cross-language byte-level conformance anchor
